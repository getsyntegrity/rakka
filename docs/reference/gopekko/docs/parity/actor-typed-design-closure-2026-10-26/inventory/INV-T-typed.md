# INV-T: Pekko actor-typed, actor-testkit-typed and actor-typed-tests capability inventory

Baseline: Pekko v1.7.1 (`9a54d1294c3ac7821bbed3c940769c3d5027d1ff`) read directly in `upstream/pekko`; goPekko `origin/develop` 9abfb40 snapshot (`develop:` in the references below); ACT2 backlog from a GitHub issue snapshot of 2026-10-25. Read-only: nothing in the repository or on GitHub was edited.

## 1. Method and search limits

Path abbreviations used in every table:
- `TY/` = `upstream/pekko/actor-typed/src/main/scala/org/apache/pekko/actor/typed/`
- `ATT/` = `upstream/pekko/actor-typed-tests/src/test/scala/org/apache/pekko/actor/typed/` (Scala specs; Java tests are under `.../src/test/java/`)
- `TK/` = `upstream/pekko/actor-testkit-typed/src/main/scala/org/apache/pekko/actor/testkit/typed/`
- `TKT/` = `upstream/pekko/actor-testkit-typed/src/test/scala/org/apache/pekko/actor/testkit/typed/scaladsl/`

What was enumerated:
- Every file under `actor-typed/src/main` (95 files: `typed/` top level, `scaladsl`, `scaladsl/adapter`, `javadsl`, `internal`, `internal/adapter`, `internal/receptionist`, `internal/routing`, `internal/pubsub`, `delivery`, `delivery/internal`, `receptionist`, `pubsub`, `eventstream`, `resources/reference.conf`, `scala-2.12/2.13/3` `Platform.scala`, `scala-jdk-9` JFR files, `mima-filters`). Public symbols were taken from definitions with `path:line` (grep of `trait|class|object|def|type`, then the declaring lines read where needed).
- Every file of `actor-testkit-typed/src/main` (scaladsl, javadsl, internal, root files, `reference.conf`, one Java annotation file).
- The file list of `actor-typed-tests/src` (Scala and Java) and the test titles of the specs named in section 3.

How "Specs observing it" was filled: spec file and line of the test title (titles extracted by a script from the test files; the assertion body was read only for `OrElseSpec.scala`). So "asserts" below is the test title, not a verified reading of every assertion. "none found" names what was searched (`grep -rn <symbol>` over `actor-typed-tests/src/test`, `actor-testkit-typed/src/test`).

What was NOT done (explicit limits, no completeness is implied):
- Internal (`private[pekko]`) files were grouped by purpose, not enumerated symbol by symbol (internal/adapter, internal routing, delivery/internal, internal receptionist/pubsub, SystemMessage, InternalMessage). Their public contract rows carry the owning public symbol.
- javadsl (12 files) is listed as a block (section 2.9) with the Java-only surface; not enumerated per method.
- The Java test files (`.java`) and `docs/` example specs of `actor-typed-tests` are mapped by file name only (section 3.2); their bodies were not read.
- ACT2 story coverage was checked from the issue titles, the `Inventory: ACTINV-` header and keyword searches over title+body of `issues_all2.json`. A story that covers a symbol under different words may be missed; a "no story found" statement means "no keyword hit", and is marked `unclassified` only after the ADR text (0033, and the other ADRs in `docs/adr`) and the GOV stories were also checked.
- goPekko state was read in `develop/pekko-actor/actor/*.go` (non-test) by symbol search; test files and `internal/` beyond `deadletter` and `mailbox` were not read.
- ADR 0032 (open PR #1014) is not in develop and was not used for classification.

Legend:
- Scope class: `included` (a story exists), `included-no-story`, `excluded-recorded`, `excluded-proposed` (a GOV story), `unclassified`, per the brief.
- goPekko state: `absent` = no `pekko-actor-typed` module exists in develop (`ls develop` shows only `pekko-actor`; ADR 0033 Evidence: "Typed has no code"). Where a Classic base exists it is cited as `Classic base: <path:line>` and is not a Typed implementation.
- Evidence/oracle (ADR 0033 D13): `none` = no Typed judge harness and no differential scenario exists (ADR 0033 Consequences; JDG-03 #1046 and JDG-11 #1047 are open and blocked). "oracle: pending determination" = a Pekko spec in `actor-typed-tests` observes the behavior, so an oracle may apply, and its applicability has not been determined. No row is classified "pending approval".
- Story keys: `#n (KEY)`. `ACTINV-n` is the epic #746 inventory id the story cites.
