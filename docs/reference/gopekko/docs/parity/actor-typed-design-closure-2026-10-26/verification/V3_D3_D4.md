## Key Learnings

1. In Pekko 1.7.1 the ProducerController resend-first timer is armed for every first message and is not conditional on a durable queue, so the reconciliation texts of #998 and #1165 and the Scaladoc are wrong or incomplete on this point.
2. The Pekko `Resend(0)` handler resends the stored unconfirmed messages before replacing its stored head with the first-marked version, so the resent messages themselves are not first-marked.
3. ADR 0010 stays `proposed` except the watch increment and the supervision Classic model, so its X1 context-expiry text must not be called an accepted Owner decision.
4. The `CoordinatedShutdown` `TaskDefinition.cancel()` returns true on every repeated cancel and the spec asserts it, while the `Cancellable` Scaladoc says false.
5. `State.cleanup` of the durable producer queue is exercised by a persistence-typed spec, so a claim of no spec in actor-typed-tests must name the module searched.
