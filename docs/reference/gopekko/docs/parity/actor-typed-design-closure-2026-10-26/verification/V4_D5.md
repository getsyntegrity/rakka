## Key Learnings

1. Pekko's CircuitBreaker Closed state resets the failure count on every success, and a single call can fire both the failure and the success listener when a custom failure function classifies a non-allow-listed failure as non-failure.
2. FutureTimeoutSupport.timeout only cancels a source guarded by an isInstanceOf CompletableFuture check, while timeoutCompletionStage cancels unconditionally, so the cancel claim for acceptance criterion three needs that distinction.
3. The ByteBufferSerializer trait has non-test users inside the actor module at Serialization.scala line 288 and in remote MessageSerializer line 97, which contradicts the claim that only the spec uses it in actor.
4. ADR 0032 text in open PR 1014 records D1 to D4, D6 and D7 as accepted with quoted Owner words but is not merged, so it must be described as not integrated rather than as a mere proposal.
5. Issue bodies that say Decision (Owner) option A for GOV-45, GOV-46 and GOV-47 quote no Owner instruction and no accepted ADR, so replacement texts should attribute them to the issue body only.
