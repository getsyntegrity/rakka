## Wording discipline

1. D13. The producer writes "oracle exists and can host a differential scenario" on every story. D13 (`0033-...md:47`) requires a differential scenario "whenever an applicable oracle exists". Saying "exists" for a spec that observes a related behavior but not the exact AC is stronger than "applicability pending determination". Use "a Pekko spec observes X (path:line)" and leave applicability pending. Affected: every "Oracle (D13)" line.
2. Producer lines that classify rows as having no oracle, which a missing spec does not show:
   - #1177: "the manual-clock requirement: does not apply (no Pekko analogue)" -> "oracle applicability pending determination; no Pekko analogue was found for an injectable clock (Typed `SchedulerSpec` is compile-only)".
   - #1096: "Oracle (D13): does not apply to the row's wiring ... D13 still requires documented alternative evidence and Owner approval" -> "oracle applicability pending determination; no Pekko behavior is mapped to this row".
   - #1180 F3 and #1177 F2 state "D13 alternative-evidence approval ... is not recorded"; acceptable as a statement of fact only if the story has no approval reference (I did not check the story bodies for an approval reference).
3. `pending approval`: the producer's replacement "oracle applicability pending determination" matches the brief. D13's own text still uses "pending approval" for Go-only adaptations; that is quoted ADR text, not the producer's default. No `pending approval` default found in the replacement texts I read.
4. ADR 0032: the producer consistently says "not integrated (PR #1014)". No place where it is presented as integrated. Good.
5. Owner decision: no Owner decision is claimed without a quote. #1170 F2 says "as in OD-2 of the prior audit" - this refers to a prior audit, not an accepted ADR; replace with "an open choice recorded in the story".
6. New design: #1176 F1 and others do not recommend design. #1174 F1/F2 fine. No recommendation of a new design found in the rows I read.
7. "per the brief" (#1180 F1) is a reference to an internal brief in a text that will be published; remove.

## Key Learnings

1. Pekko publishes the restart-stash overflow `Dropped` with `ActorRef.noSender` because the three-argument factory is used (Supervision.scala:123, ActorRef.scala:629).
2. The typed ask against a terminated or missing actor fails with a `TimeoutException` stating "had already been terminated" (AskPattern.scala:150, AskSpec.scala:71-130).
3. SupervisionSpec.scala:1671 is a comment excluding Resume from a test, so no Pekko spec asserts that setup does not rerun under Resume.
4. Plan rows disagree on whether module skeleton H-01 needs A-03 (delivery-plan.md:366 versus :558), while the #1096 body states the #1021 edge itself.
5. The producer's "oracle exists" phrasing is stronger than ADR 0033 D13, which leaves applicability pending until it is determined.
