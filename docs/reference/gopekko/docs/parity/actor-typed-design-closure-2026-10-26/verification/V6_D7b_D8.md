## Key Learnings

1. Pekko has doc and integration tests outside actor-testkit-typed that exercise the testkit, such as cluster-sharding-typed's AccountExamplePersistenceProbeDocSpec which calls runAskWithStatus, expectDone and receiveStatusReply.
2. ActorContextAdapter.stop throws IllegalArgumentException for any ref that is not a direct child, so it is not a silent no-op as the D7b producer wrote.
3. ActorRefSpec lines 422-440 assert that messages sent before a PoisonPill are processed before the actor terminates, and DeathWatchSpec lines 216-245 use the default decider with Kill and observe the stop indirectly.
4. The D7b boilerplate D13 sentence is conditional and compatible with ADR 0033, while three specific ACs in the 1150, 1153 and 1154 stories do apply pending approval where a Pekko source exists without a spec.
5. ADR 0033 contains no list of the seven exclusion reason codes; they live in the design dossier at line 342, so story bodies that cite them as D13 text misattribute them.
