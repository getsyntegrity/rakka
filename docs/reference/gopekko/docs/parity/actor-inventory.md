## Meaning of 100%

Quoted from [ADR 0033](../adr/0033-actor-typed-scope-and-architecture.md) D7:

> "100%" means coverage of the local capabilities included in the inventory matrix, with the distributed-systems exclusions and the JVM-only exclusions enumerated explicitly. It is not total parity with Apache Pekko, which includes cluster and remoting. Every module README and every closure report states this.

Closure reports follow this meaning. **This document asserts no Pekko parity**: no row below is implemented, complete or V3 unless the plan already says so or an Owner decision recorded in its V label says so (the plan marks none V3; the Owner assigned V3 to C-08a, C-08b, C-08c and D-01a on 2026-11-09, each with the evidence in its row). Binding rules: ADR 0033 D8 (per-subpackage scope with recorded exclusions) and D13 (V3 needs a differential scenario on Pekko when an applicable oracle exists; otherwise alternative evidence plus explicit Owner approval; until then `pending approval`).
