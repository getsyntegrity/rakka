This document grows by appended sections; **sections 2 to 4 (state of the source-reading rows, conflicts, limits) arrive with O1d**, and until then it claims only the scenarios whose logs are in the tree.

Harness `docs/parity/harness/src/main/scala/restartcap/Run.scala`, sha256 in `restart-stash-capacity-2026-11-13.logs/harness-files.sha256`; shape of `restartstash.Run` (`restart-stash-held-2026-11-11.md`): `A` = `supervise(setup).onFailure[IllegalStateException](restart.withStashCapacity(n))`, child `c1` whose `PostStop` blocks, watched actor `X`, a hook outside the supervisor that proves by a counter what the supervisor retained. ## 3. Conflicts with the scope

None among the rows observed: capacity 0 drops all and the restart completes; the arriving entry is discarded and the retained prefix keeps its order; a negative per-strategy value means the system default; the same stash survives a failure during the replay. The nested-supervisor rule of open item 4 is **neither confirmed nor contradicted** (section 2). One detail the scope does not state: the invalid system default (`CPS`) fails when the **system starts**, not at the first restart.

## 4. Limits

Classic `ActorSystem` hosting Typed actors, default dispatcher, one JVM per run, Java 1.8.0_504 only. `Dropped` lines come from a collector on the event stream, so their position relative to `hook`/`A` lines is not a proof of order across threads; the content and count are. The shipped `SupervisionSpec` (Option 1 of earlier oracles) was not re-run: the harness uses the Maven jars, and no copy of `upstream/pekko` was built. The 21 runs were made once, from the head `0686a36a` tree whose harness hashes are recorded; CI (`ci-fast`) does not run the harness, so the logs are the only evidence of the runs.
