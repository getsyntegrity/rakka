## What this delivers

`StashBuffer.UnstashAll(behavior)` and `StashBuffer.Unstash(behavior, n, wrap)`: the buffered messages (the first `n`, or all that are in the buffer when the call is made) are given in order, one at a time, to `behavior` and to the behavior each one returns; the result is the final behavior, which the handler returns. A failure while replaying keeps the behavior that threw (`UnstashException`), so supervision continues with it. When the behavior becomes `Stopped`, the replay ends and every message not yet interpreted is published once, in order, as a dead letter whose message is `wrap(msg)`, whose sender is the `deadLetters` ref and whose recipient is the stashing actor (#1169).

## Proposed Go shape (decisions for G2, each with its Pekko line)

- **D-1 (approved). Signatures.** `func (b *StashBuffer[T]) UnstashAll(behavior Behavior[T]) (Behavior[T], error)` and `func (b *StashBuffer[T]) Unstash(behavior Behavior[T], n int, wrap func(T) T) (Behavior[T], error)` (`SBI:156-160` unstashAll = `unstash(behavior, size, identity)` then `stashCleared`; `SBI:162-185` unstash; `scaladsl/StashBuffer.scala:142, 165`, bodies and doc read). **`wrap == nil` is the identity** (Owner, 2026-11-10): `unstashAll` itself passes the identity (`SBI:157`, `ConstantFun.scalaIdentityFunction`), and `unstash` with a null `wrap` would fail at `wrap(node.message)` (`SBI:199`, `SBI:251`); marker `TODO(TYP-14-nil-wrap)`. The error replaces the exceptions: an `Unhandled` starting behavior (`SBI:229-230`, `IllegalArgumentException`; test `StashBufferSpec.scala:261-265`) returns `ErrUnstashUnhandled`; a failure of a replayed handler returns the unexported `unstashError` (D-4, no export). `stashCleared` (`SBI:158, 264`) is a no-op hook with no Go consumer: not ported.
- **D-2 (approved). Eager, not lazy.** Replay runs inside the call, as Pekko's does (`SBS:106-127, 152-185, 231-259` call `unstashAll` outside any actor and read the effects at once; handlers `stash`/`clear` the same buffer while it runs). A lazy marker behavior would break those cases. So the replay engine is a function independent of the interpreter: it takes the buffer, the starting behavior and a context.
- **D-3. The result keeps its supervision layers.** The replay starts `behavior` with the existing `startInto` (collects `Supervise` layers, `SBI:193, 227` = `Behavior.start`, `BEH:198-211`); the result is a new sealed variant `startedB[T]{r receiveB[T]; layers []layer[T]}` that `turn` installs as it installs a started `Setup` today (`interpreter.go:262-271`), keeping each layer's original `initial` so that a restart rebuilds the original behavior, not the replayed one (Pekko's `SuperviseBehavior.replaceNested` keeps `initial`). `Same` as the starting behavior means "the current behavior of the actor" (`SBI:231-236`, `SS:331, 349, 371, 394, 419, 712`), so the typed `Context` gets an unexported link to the interpreter that gives it (and, on a nested unstash, the behavior in progress, `SBI:166-168, 194`).
- **D-4 (approved with a condition). `UnstashException` is an unexported error type.** `type unstashError struct{ cause error; behavior ... }` with `Unwrap() error` returning `cause`; unexported as Pekko's is (`private[pekko]`, `SBI:271-286`). **Where Pekko unwraps the cause to decide supervision (read):** `Supervision.scala:74-76` (`isInstanceOfTheThrowableClass` matches `UnstashException.unwrap(t).getClass`, so the `OnFailure` type is tested against the cause), `:98-102` (the log uses the unwrapped message), `SBI:272-275` (`unwrap` returns the cause of an `UnstashException`, the exception itself otherwise); and where it uses the carried behavior: `AA:152-160` (`behavior = e.behavior; throw e.cause`), `SUP:174` (Resume), `:318, 327` (Restart: `PreRestart` to `e.behavior`), `:416` (the restart path shared by Restart and Backoff). In Go `Unwrap()` makes `errors.Is/As` (the matchers `ErrorIs`/`ErrorAs`) see the cause, so matching needs no extra code; the interpreter's `fail` extracts the error with `errors.As`, installs the behavior that threw before the supervisor acts, and then applies Resume (continue with it), Restart (`PreRestart` to it) or the default Stop (`PostStop` to it). **Mandatory test (condition of the Owner), slice B: `TestUnstashAll_SuperviseErrorIsCatchesFailureDuringReplay`: `Supervise(...).OnFailure(ErrorIs(cause), Restart()/Resume())` catches a failure raised by a handler during the replay, matching on the cause and not on the wrapper;** mutation: the matcher sees the wrapper (`Unwrap` removed) and the test fails by assertion. A twin test with `ErrorAs`.
- **D-5. Other rules of the loop, as written.** `Same` result keeps `b2`; `Unhandled` result keeps `b2` and records the message through the existing `onUnhandled` hook (`SBI:209-217`, `SS:636`); only the messages in the buffer at the call are replayed, with `n = min(n, size)` (`SBI:178`; a `n <= 0` replays nothing but still starts the behavior: Scala `take(0)`); an empty buffer returns `behavior` untouched, unstarted (`SBI:163-165`); a message stashed during the replay waits for the next call (`SBS:152-185`); `Clear` during the replay stops the iteration because the iterator checks `nonEmpty` (`SBI:171`, `SBS:231-259`). `wrap == nil` is the identity (Pekko's `null` would NPE; conservative rule, `TODO(TYP-14-nil-wrap)`).
- **D-6. The usage rule of the captured context (pending since #889 S7c).** The buffer holds the `*Context[T]` of the `Setup` that built it (`stash.go`, D-7 of #889); its inner `actor.Context` is one object for the life of the cell (`pekko-actor/actor/spawn.go:156`, pinned by S7c). **Rule:** every method of the buffer, `Stash`, `Clear`, `Unstash`, `UnstashAll`, is called only from the actor's own turn, that is from a message or signal handler, a `Setup` factory or the callback of `ForEach/Exists` of that incarnation; never from another goroutine, after `PostStop`, or from the previous incarnation's buffer after a restart (a restart reruns `Setup` and builds a new buffer, as Pekko's). The replayed handlers receive the buffer's captured context (Pekko passes the buffer's `ctx`, `SBI:179`, `203`), whose only per-turn state is the interpreter link of D-3; the sender seen by `Context.Sender()` inside a replayed handler is the one of the message being handled when `UnstashAll` was called (Typed has no sender). Not enforced, documented in the README and the doc comments, as for `Context` itself (`context.go:15`). A test pins that a handler that calls `UnstashAll` through the captured context of an earlier turn replays correctly (the same cell), and the README states the rule.
- **D-7 (approved; contract is the oracle). Dead letters (#1169).** `unstashRestToDeadLetters` (`SBI:246-252`): for each remaining node, a `DeadLetter` whose message is `wrap(msg)` is published through `ctx.System().DeadLetters()` (`Context.System()` from #1182 slice B). Called when the behavior to start is not alive (`SBI:238-243`) and when a result is not alive (`SBI:218-223`). Messages already interpreted are not published; a replay that stays alive publishes none. **The sender and recipient fields of that dead letter are the observed values of the Pekko oracle that another agent runs in its own PR (`docs/parity/oracles/`); they are the contract, not an inference from `SBI:249-251`.** **Slice C starts only after the merge of #871 and of that oracle PR** (as slice B of #1182).
