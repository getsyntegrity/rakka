## 4. Invariants (each is a test)

- **Grammar.** `protocol "://" system "/" [ element *( "/" element ) ]`; protocol `[A-Za-z][A-Za-z0-9+.-]*` kept exactly as written (never folded); system `[a-zA-Z0-9][a-zA-Z0-9-_]*`, enforced by the parser only; elements by `checkPathElement` unchanged (non-empty, no `/`, no `#`, Pekko's character set, `%XX` verbatim, `.` and `..` legal, no navigation). `pekko://sys/` is the root.
- **Position rule, no new sentinel.** Steps: (1) split at the first `://`; (2) protocol; (3) system part up to the first `/` or the end; (4) path part. A failure in steps 1-3 is wrapped `ErrInvalidAddress` (no `://`, empty or malformed protocol, empty system, a system character outside its shape, `@` and `:` naming the unsupported host/port form per ADR 0031 O1, `#`, `?`, `%`, space, control characters in the system part); a failure in step 4 is `ErrInvalidPath` (the missing root slash of `pekko://sys`, an empty element, a trailing slash, an invalid element, `#` or `?` in the path, a bad `%`). Errors are `fmt.Errorf("%w: ...", sentinel)`; a rejected input returns the zero `ActorPath`.
- **Rows.** P1-P24 and X1-X9 of the scope with their outcomes; P3-P5, P12, P13, P23 are errors in Go although Pekko accepts them (rows 39/44, 45/50, 51/56, 69/74, 75-80: accepted differences, Q2 and Q6); P22 `my_sys` is accepted in Go although Pekko's own `fromString` rejects it (rows 81-86).
- **Round trip, restricted.** For every `ActorPath` built over a non-zero `Address` whose protocol and system satisfy the shapes, `parseActorPath(p.String()) == p`. **Documented consequence (Q4, parser-only enforcement):** an `Address` made by `NewLocalAddress` with other characters is constructible; for the system `a/b`, `pekko://a/b/x` parses to system `a`, path `b/x`. A test pins it as the documented behavior so a future G10 decision changes it knowingly.
- **No lookup (AC3).** The parser draws no ID and creates no actor: tested through the `idMint` seam and `idSeq`.
- **Reuse.** `NewLocalAddress`, `NewRootPath`, `Child` and `checkPathElement` are unchanged; `address.go`, `actor_path.go` and `names.go` are not edited.
