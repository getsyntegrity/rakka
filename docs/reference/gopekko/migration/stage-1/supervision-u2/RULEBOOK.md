## 1. Decisions this RULEBOOK asks the Owner to confirm by approving its hash

- **D1 exported names.** `Restart` (value 2, as the stub); `InitializationError{Err error; InRestart bool}` with `Error`/`Unwrap` as the stub; `FailedMessage` with `Value() (any, bool)` as the stub and **no exported constructor** (the runtime builds it); `ChildFailure{Child Handle; Cause error}`; `PreRestarter[T]` and `PostRestarter[T]` as the stub. `ErrGoexit`, `AllForOne`, `DefaultStrategy`, `StoppingStrategy` stay **not exported** (U3, U6). The conversions of S4 (`windowMillis`, `windowNanos`, `retriesOption`) stay **unexported**, as the stub says. `PreRestartException`/`PostRestartException` do not exist as types: `InitializationError{InRestart: true}` stands for `PostRestartException`; the pre-restart failure is only an event (D13). **The `originalCause` of `PostRestartException` (`Actor.scala:247-251`) is not carried** (the stub has no field): recorded as a limitation.
- **D2 `Restart` is delivered; value 2 stops being invalid.** `Directive(2)` is `Restart`; the zero value and values above 4 stay invalid (`ErrInvalidDirective`). This **supersedes** U1 D2 for the value 2 and makes the U1 row `{"two with ok", Directive(2), true, "invalid"}` false: the loop replaces it by `{"six with ok", Directive(6), true, "invalid"}` plus a row that `Restart` with ok is applied (kept in the same table). Rows with `ok == false` are unchanged.
- **D3 `FailedMessage` content (A12, S8).** For a failing `Receive` it is the message `T` as received (present, value kept, never copied or converted); for a parent that fails **while it handles a `Failed`** (Escalate, decider panic, `ErrInvalidDirective`) it is `ChildFailure{Child, Cause}` of that `Failed` (`dungeon/FaultHandling.scala:306`; the escalated and the failing-decider cases, ADR A2/A12); **absent** for a failure of `PreStart` or of the new instance, and for a restart requested of a surviving child; the stale-message case after a `Resume` is D22. A message delivered through `WatchWith` is a `T` and so the user-message case. The `Terminated` case of A12 is a death pact, which still stops directly (U3): **PORT-GAP(death-pact-U3)**. A present nil value is a Go-side test labelled "valid only while #452 admits nil".
- **D4 hooks and defaults.** `PreRestart(ctx, cause, FailedMessage)` has no return value; a panic in it is recovered, reported as the event `prerestart-failed`, and the restart goes on (`dungeon/FaultHandling.scala:102-108`). `PostRestart(ctx, cause) error`: an error or panic is the failure of rule R9. **Custom replaces default, as an override does**: if the instance implements `PreRestarter`, the runtime runs only that; if it implements `PostRestarter`, only that. The defaults (`Actor.scala:625-631`, `643-645`), run by the runtime for an instance that implements neither: `PreRestart` = unwatch and stop **every child**, then `PostStop(old)` if implemented; `PostRestart` = `PreStart(new)` if implemented (its error is the failure). **No exported helper to call the defaults from a custom hook** (Pekko's `super.preRestart`): a recorded gap, to be opened as an issue at the PR; tests that need it write the two steps by hand with `ctx.Stop`/`Unwatch`.
- **D5 factory retention (A8).** The cell retains the factory given to `Spawn` (`spawn.go` assignment only) and runs it **once per restart, inside the restarting activation**, never on the thread that sent the `Recreate`. A nil actor or a panic of the factory in a restart is `InitializationError{Err: ErrNilActor or the error wrapping ErrFactoryPanic, InRestart: true}`. The `Spawn` contract is **not** changed (U4 reconciles it); `errors.go` is not touched.
- **D6 `PreStart` failure of the first start is supervised (supersedes U1 D6 and test V15).** Under a parent that declares a strategy the failure emits `prestart-failed`, then reaches the decider as `*InitializationError{Err: cause, InRestart: false}` (`Err` = the returned error as is, or `*PanicError` for a panic; `ActorCell.scala:642-683`); the cell is suspended and **no `stop-accepted` follows**. Under a parent that declares none, or at top level, the behavior is today's (`prestart-failed` then `stop-accepted`). A `PostStop` failure is unchanged (`poststop-panic`). The loop rewrites `TestSup1Initialization` (V15) for this: decider consulted once with an `*InitializationError`, `Stop` stops the child, `Restart` creates a new instance (R12).
- **D7 states "never initialized" and "failed fatally".** Pekko's `actor == null` is the Go state **init-failed** (the first `PreStart` failed and was reported); `isFailedFatally` is **fatal** (the new instance or `PostRestart` failed). Their effects are R12 and R9. `Resume` and `Restart` in these states are **converted**, not ignored (R12), and the conversions never consult the budget.
- **D8 children and order of the restart (S6, H3).** The order is fixed by R5-R8. The restart waits **only** for the children whose stop this cell requested (`Context.Stop` of a child, or the default `PreRestart`); survivors do not hold it. `PostStop(old)` from the default `PreRestart` runs **at once, without waiting for the children** (H3). Stash of `suspend`, `resume`, `recreate` and `failed` while waiting is rule R11.
- **D9 the `PostStop` guard and S11.** The **default** `PreRestart` calls `PostStop(old)` **through the per-cell guard** (`beginPostStop` semantics), and the guard is **re-armed when the new instance is installed**, so the final termination calls `PostStop` once on each instance that reaches it. A Stop that arrives during the wait therefore finds the guard set and calls it **once** (the interim of section 0). The guard applies **only to the default hooks**: a custom `PreRestart` that calls `PostStop` itself is user code with no guard (D21).
- **D10 budget (S4, A4, A6).** `Budget{MaxRetries int32; Within time.Duration}` and `OneForOne(budget, decide)` keep their U1 signatures. The statistics are **unexported**, per child incarnation, stored by the parent. `Budget{}` denies every restart and is never presented as a default. Only `Restart` consults it (`FaultHandling.scala:673`); `Resume`, `Stop`, `Escalate` and the conversions of R12 never do.
- **D11 clock for the window (A5).** The window start is an `int64` nanosecond reading where `0` means "not started", exactly as `FaultHandling.scala:73-78`; readings may be 0 or negative; **no explicit flag** (Owner decision of 2026-10-14). Source of the reading: **recommended**, a new unexported `options.nanotime func() int64` seam (`system.go`), default a monotonic reading since the system was created; a test injects scripted readings. It does not change the `clock` interface (that would break `fakeClock`, an existing read-only test). Alternative (Owner may choose): `clock.Now().UnixNano()`, which needs no `system.go` change but follows wall-clock jumps (not what `System.nanoTime` is). This RULEBOOK recommends the seam.
- **D12 the trapExit decider.** `MakeRestartDecider[T any](causes ...error) Decider[T]`: a cause that matches one of `causes` by `errors.Is` gives `(Restart, true)`, any other gives `(Escalate, true)` (`FaultHandling.scala:260-262`; U1 D8 moved this form here). Name PROPOSED (**Unknown in the ADR**); the Owner confirms or renames. Tests that use `classOf[Exception]` or `classOf[Throwable]` use `DeciderFunc` returning `Restart` for any cause.
- **D13 events (A11).** Names and payloads PROPOSED; no existing event changes: `restart` (after the new instance finished `PostRestart`, or after the new instance of R12 started; detail = the cause), `restart-denied` (budget denied; detail = the cause), `prerestart-failed` (D4; detail = the recovered value), `restart-failed` (rule R9; detail = the `*InitializationError`). They are an additional observability channel, never a replacement for `loggingEnabled` (U9).
- **D14 interim paths unchanged.** Section 0 plus: the `Goexit` paths (`abortGoexit`) must not regress; a `Goexit` in `PreRestart`, `PostRestart` or the factory is **not classified** (U3 `ErrGoexit`), but the cell must not hang: it takes the existing `abortGoexit` route (stop accepted), covered by one test that only asserts termination.
- **D15 attribution layout of the new test files.** `.github/scripts/check-headers.sh` requires **exactly one** `// Ported from upstream/pekko/...scala` line per ported file. U2 ports from eleven Pekko files into three Go files, so each file carries **one** such line (primary source, fixed in R4.1) and the other sources as `// Also adapted from <path>` lines, which the gate does not count; `manifest.tsv` lists every pair. **Alternative** (Owner may choose): one test file per Pekko source (eleven files, a longer writable list). The ported-file attribution is a licensing statement: the Owner confirms the layout.
- **D16 U1 precisions, OPEN again for U2 (not assumed).** (a) Transitional behaviors are labelled transitional, never Classic parity (section 0 interim). (b) `errors.Is` only for matching causes; no `errors.As` target is carried by `CauseDirective`/`MakeRestartDecider`. (c) `ContextMisuse` does not exist, so context-expiry stays `PORT-GAP(context-expiry)` and no expiry is added. (d) What remains Unknown stays Unknown (R17). The recommended answer for each is the U1 answer; the Owner confirms or rejects each by approving this RULEBOOK.
- **D17 test classification.** Portable, adapted, moved and omitted assertions, the Go-side scenarios and the mutant list are fixed in section 5 and are the Owner's by approving the hash.
- **D18 the soft stop at 1,120,000 tokens (OPEN Owner decision; RUNBOOK 3).** The Owner approved a stop at 1,120,000 "para evaluar lo restante". The cumulative forecast crosses it after the two reviewers, so it is a planned evaluation point. **Recommended answer:** at the stop the orchestrator records observed against forecast and proceeds autonomously with the remaining mandatory steps (fixer, fix-delta review) when `observed + their forecast <= 1,400,000`; it asks the Owner only when the projection passes the cap. The alternative is to ask the Owner at every crossing.
- **D19 recreate to a terminated child (Q1; recorded Pekko fact, R8).** In Pekko an unanswered `Recreate` sent to a terminated child is dead-lettered. **Recommended answer:** Go does **not** publish a restart request as a dead letter (the internal restart request is not a user message, and the existing dead-letter contract is for user messages); recorded as a declared Go difference, `PORT-GAP(recreate-dead-letter)`. The alternative is to publish it.
- **D20 order of restart requests to survivors (Q2; recorded Pekko fact, R8).** Pekko sends them in ascending lexicographic child-name order, which is only the send order. **Recommended answer:** Go sends the restart request to survivors in ascending name order and does not assert the order in which the restarts take effect.
- **D21 custom `PreRestart` that calls `PostStop` (Q3; observed in Pekko, R17).** **Recommended answer:** Go adds no guard for user code, so two calls on the old instance when a Stop arrives during the wait is the faithful result (the observed Pekko count). The guard of D9 applies only to the default hooks. The alternative is to guard custom hooks too (a deviation).
- **D22 the message after `Resume` (Q4; recorded Pekko fact, R17).** **Recommended answer:** Go keeps the last failed message until the next successful `Receive` (faithful to Pekko) and passes it as the present `FailedMessage` of a later restart that has no new message. The alternative is to clear it on `Resume` (a deviation).

## 2. Behavior specification (the implementer follows it; it is not open design)

Format: Source -> Observable -> Go adaptation. The mechanism is the implementer's wherever a rule says "Go: observable".

R1. **Restart directive and permission.** Source: `handleFailure` `Restart` -> `processFailure(restart = true)` (`FaultHandling.scala:378-381`, `666-677`): `if (restart && stats.requestRestartPermission(retriesWindow)) restartChild(child, cause, suspendFirst = false) else context.stop(child)` (`:673-676`); `restartChild` sends `Recreate(cause)` (`:448-452`, `dungeon/Dispatch.scala:160-162`). Observable: an allowed restart sends the already suspended failing child a restart request; a denied one stops it; siblings are untouched. Go: `apply` for `Restart` asks the budget (R2) and then either delivers `recreate{cause}` to the failing child, or `acceptStop(nil)` and emits `restart-denied`. `Stop`, `Resume` and `Escalate` do not ask (D10).
R2. **Budget algorithm.** Source: `ChildRestartStats.requestRestartPermission` (`FaultHandling.scala:58-88`) on `(retries: Option[Int], window: Option[Int ms])` with `retriesWindow` (`:660-662`), `maxNrOfRetriesOption`, `withinTimeRangeOption` (`:303-307`). Observable: `(Some(n), _)` with `n < 1` denies; `(Some(n), None)` increments and allows while `count <= n`; `(x, Some(w))` uses the window rule with `x.getOrElse(1)`; `(None, _)` allows. Window rule: `retriesDone = count + 1`; `windowStart` = the stored start, or `now` (stored) when the stored start is `0`; inside iff `now - windowStart <= MILLISECONDS.toNanos(w)`; inside: `count = retriesDone`, allow iff `retriesDone <= retries`; outside: `count = 1`, start = `now`, allow. Go: exactly that on `int32` counters and `int64` readings (`Budget -> (retriesOption, windowMillis)`, `windowNanos`), the arithmetic wrapping like Scala's `Int` (A6). The 24 cells (`a2a4-sbt.out:442-465`) and the 13 conversions (`winconv/main.go:30-43`; `toNanos(-2147483648) = -2147483648000000`) are the oracle.
R3. **Zero reading (A5).** Source: `:73-78`, `:84-86` (both the first request and the reset store `now`; stored `0` means "not started"). Go: the same, with `nanotime` readings (D11). Oracle: `a5-edge/oracle.out:1-20` (E1-E5; **derived from the source, not from a Pekko run**).
R4. **Statistics per child.** Source: `ChildRestartStats(child, count = 0, windowStart = 0)` created at `initChild` (`Children.scala:171-181`), read only for a currently known child whose `uid` matches (`dungeon/FaultHandling.scala:313`). Observable: the statistics survive the restarts of that child and start fresh for a new child, even under the same name; two children never share them. Go: keyed by the incarnation ID in the parent; a stale `Failed` (U1 rule 1) charges nothing.
R5. **Recreate dispatch.** Source: `faultRecreate` (`dungeon/FaultHandling.scala:92-118`) and the stash rule of `systemInvoke` (`ActorCell.scala:481-546`). Observable: (a) init-failed -> R12; (b) a normal cell -> R6-R8; (c) a cell that is already restarting or stopping -> the request becomes a plain resume that keeps the suspension counter balanced (`:115-118`), **no second restart**. Go: `recreate{cause}` is a system item of the child, taken at the next system boundary **even while the cell is suspended**, ahead of user messages; it is never an item of the runtime lane (U1 rule 1). Delivery to a finished cell is a no-op.
R6. **PreRestart on the old instance.** Source: `:98-112`; defaults `Actor.scala:625-631`. Observable: `preRestart(cause, message)` runs on the **old** instance unless the cell is failed fatally; a failure is only reported; then the current message is cleared (`ActorCell.scala:718-721`). Go: D3, D4; run in the cell's activation with no lock held; the default stops and unwatches every child, then `PostStop(old)` through the guard (D9).
R7. **Wait for children.** Source: `:113-114`, `Children.scala:183-189`, `246-262`, `dungeon/FaultHandling.scala:327-351`. Observable: if any child whose stop this cell requested is still alive, the restart is suspended and resumes when the last of them is removed; otherwise it continues at once; names of those children are free when it continues. Go: D8; the wake-up is evaluated when the restart begins and after every completion of such a child, and the continuation runs **inside an activation of the cell** (A8). No user message is processed while waiting, whatever the counter (the guard is separate from the counter, see R11). `readyLocked` keeps its anchor text (section 0).
R8. **finishRecreate.** Source: `:278-297`. Observable, in this order: snapshot of the surviving children; counter -1 for this cell and the failed mark cleared; the factory builds the new instance (A8); `PostRestart(new, cause)` (default `PreStart`); each survivor receives a restart request **in turn**, an error sending it only reported. The restart requests are **sent** in ascending lexicographic child-name order (children are an immutable `TreeMap` keyed by name: `dungeon/ChildrenContainer.scala:79,120,174`; the loop is `dungeon/FaultHandling.scala:293`); each survivor processes its request on its own mailbox, so the order in which the restarts take effect is not defined and not asserted (D20). A request sent to a terminated survivor is dead-lettered in Pekko (`dungeon/Dispatch.scala:160-162`; the closed mailbox is swapped in at `dispatch/AbstractDispatcher.scala:243`, `dispatch/Mailboxes.scala:62-63`; `Recreate` has no `DeadLetterSuppression`, `dispatch/sysmsg/SystemMessage.scala:231`, unlike `Terminate`, `:247`); whether it is logged is configuration. Go: D19. Go: the same; the new instance becomes the actor of the cell; a survivor's restart is R5 on its own cell.
R9. **Failure of the new instance (S10).** Source: `:298-302`, `Actor.scala:247-251`. Observable: the cell is marked failed fatally, its actor fields are cleared (so `preRestart` is skipped next time, `:104`), and the cell fails **again** with a `PostRestartException`, reported to the parent, suspended again, survivors not suspended again (`childrenNotToSuspend = survivors`). Go: `*InitializationError{Err, InRestart: true}` through the U1 failure path with the skip rule applied to the survivors; event `restart-failed`; `FailedMessage` absent. A later `Restart` skips `PreRestart` and runs R7-R8 again (`SupervisorSpec.scala:419-458`); a later `Resume` of the perpetrator is R12(b).
R10. **Mailbox, identity, watches.** Source: `ActorCell.scala:718-721` (`clearActorFields` touches only `currentMessage` and the behavior stack), `dungeon/FaultHandling.scala:92-118` and `278-303` (no `tellWatchersWeDied`, no `unwatchWatchedActors` on a restart; they are in `terminate`/`finishTerminate`, `:185`, `:266-268`); S7, S9. Observable: same cell, mailbox, `Ref`, ID, name and `Done`; queued and arriving messages kept in order and processed by the new instance; both watch sets kept; **no `Terminated` is delivered because of a restart**; the final stop delivers exactly one. Go: a restart must not take the stop path (`acceptStop` withdraws the actor's own watches, `stop.go`), must not dead-letter anything, and must not touch `watching`, `watchers` or `lane` except through the default `PreRestart`'s unwatch of the children.
R11. **Stash while waiting.** Source: `shouldStash` (`ActorCell.scala:506-511`) with `Recreate`, `Suspend`, `Resume` and `Failed` being `StashWhenWaitingForChildren` (`SystemMessage.scala:215-242`, `274-277`); `Terminate` is not (`:215`). Observable: while a cell waits for children, a suspend, resume, restart request or child failure addressed to it is held and applied **in arrival order after `finishRecreate` returns**; a stop is not held. Go: observable; the suspension counter is **never clamped by a resume that arrived early**, and a held `Failed` is decided after the restart is complete, never before. This is the `StashWhenFailed` rule of U1 rule 3 extended to the wait.
R12. **Conversions and Create.** Source: `faultResume` (`:136-153`), `faultCreate`/`finishCreate` (`:158-178`), `create` (`ActorCell.scala:642-683`), `faultRecreate` first branch (`:93-96`). Observable: (a) init-failed and any `Resume` or `Recreate`: **Create** — all children are stopped (no `PreRestart`, no `PostStop` of the discarded instance), the cell waits for them, the counter -1, the factory builds a new instance and `PreStart` runs (**not** `PostRestart`); a failure there is again `InitializationError{InRestart: false}` and counts as a new failure; (b) failed fatally and a `Resume` that carries the cause (the perpetrator only, `Children.scala:216-222`): converted to `Restart(cause)` (R5); a descendant that was only resumed along the way (cause absent) is a plain resume; (c) otherwise plain `Resume` (U1 rule 6). None of these charges the budget. Go: a `Resume` of a perpetrator carries the cause to it and not to the others.
R13. **InitializationError causes.** Source: `ActorCell.scala:642-683`, `Actor.scala:198-251`. Observable: `PreStart` failures are initialization failures reported to the parent, whose decider sees one class; `Stop` is the default decision (U3). Go: D6 (`InRestart: false`) and R9 (`InRestart: true`); `errors.As` finds the type and `errors.Is` the wrapped cause (`Unwrap`); `Receive` failures keep U1 D3 (the error as returned, `*PanicError`).
R14. **Counters across a restart.** Source: `faultSuspend`/`faultResume` (`:124-153`), `resumeNonRecursive` at `:283` and `:172`, `Children.scala:209-222`. Observable: a restart of the failing child and of its survivors leaves every counter at the value it had before the failure; siblings are never suspended or resumed; the survivors balance their suspension through their own restart. Go: restarting a cell takes **one** off its own counter (non-recursive) and the recursion happens through the survivors' own restarts.
R15. **PostStop and termination.** Source: `Actor.scala:625-631`, `dungeon/FaultHandling.scala:247-257`. Go: D9. The termination path keeps calling `PostStop` once, on the current instance.
R16. **Data race.** Go-specific: the cell's actor is replaced inside its own activation; every read of it from another goroutine (`declares`, called from a failing child) takes `c.mu`. `go test -race` is the gate.
R17. **Resolved from the pinned source, and what stays Unknown.** Resolved: (1) a custom `PreRestart` that calls `PostStop()` itself, with a Stop during the wait: **observed** with a `custom-poststop` mode of the H4 reproduction against the pinned export, 3 runs, each `C#1.postStop=2 C#2.postStop=0 constructors=1 postRestart=0 W.Terminated=1` (evidence outside the repository: `goPekko-evidence/u2-semantics-probe/custom-poststop.out` and `H4Repro.scala` beside it). Mechanism: a `Terminate` is not stashed (`dispatch/sysmsg/SystemMessage.scala:247`, against `StashWhenWaitingForChildren` on `Recreate`, `:231`), replaces the `Recreation` reason by `Termination`, abandons the restart, and `finishTerminate` calls `postStop` on the old instance (`dungeon/FaultHandling.scala:188-200,247-254,345-348`); the user's own call is the first of the two. Go: D21. (2) The send order of the restart requests among survivors is ascending name (R8, D20); the order in which they take effect is not defined. (3) A `FailedMessage` seen by a restart of a cell that earlier failed, was resumed and processed nothing since: Pekko keeps `currentMessage` until the next successful `invoke` (set `ActorCell.scala:553`, cleared only after a successful return `:559`); `faultResume` does not touch it (`dungeon/FaultHandling.scala:136-153`); `faultRecreate` builds the `preRestart` argument from it (`:101`); `clearActorFields` clears it after `preRestart` returns (`ActorCell.scala:718-720`). So that restart passes the earlier failed message as `Some(M)`. Go: D22. (6) A `recreate` to a child that finished is dead-lettered in Pekko (R8). Go: D19. **Still Unknown:** (4) `PostStop` of an instance whose first `PreStart` failed and then stopped: Go runs it (existing contract, ADR 0012), Pekko does not (`actor == null`, `:254`); a pre-existing divergence, not asserted. (5) The `originalCause` of a `PostRestartException` (D1). Whether the dead letter of (6) is logged in Pekko is configuration, not decidable by reading.
