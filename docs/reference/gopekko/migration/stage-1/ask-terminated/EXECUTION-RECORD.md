## 1. Contract and scope

Approved by the Owner: F1-F6 and the exported `ErrRecipientTerminated`. A target whose termination **completed** (the `done` channel of its cell is closed) makes `ask` create the endpoint, move it to the new unexported terminal state `rejected` before `build`, call `build` once, send the request with `Tell` (which dead-letters it exactly once) and return `ErrRecipientTerminated`; no timer is armed, the context is not read again and nothing waits. A target that only **accepted a Stop** is not terminated: the Ask stays pending until its deadline or its context ends. The pre-check order of #165 is kept: a terminated target is still a valid target (`askTarget` unchanged, ADR 0015 D6); a canceled, expired or deadline-less context is resolved before `build` and the send. The check is a point-in-time read; the window between it and the send is accepted (as the typed `isTerminated` read). `ErrRecipientTerminated` has no cause.

Source: typed `AskSpec.scala:71-82` (adapted: Pekko fails with a timeout text, goPekko with a distinct sentinel) and `AskSupport.scala:312-319, 372-376`. AK18, AK19a, AK19b and the tail of AK22 are Go-specific rows. No Pekko parity is claimed and no Pekko oracle (sbt) was run. The Pekko cases for dead letters, an empty ref and a nonexistent actor have no Go analogue: `PORT-GAP(terminated-nonexistent-target)`.
