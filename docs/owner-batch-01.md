# Paquete de decisiones para el Owner — lote 01

Generado el 2026-11-18 para las unidades de la **Ola 0 y la Ola 1** de `docs/unit-plan.md`, más las **8 decisiones blocking** y las **transversales Q-X abiertas**. **Nada de esto está aceptado:** todas las recomendaciones siguen `proposed`/`blocking` en `docs/decisions/register.tsv` hasta que respondas; entonces se registran en `docs/decisions/owner-decisions.tsv` con tu respuesta, se regenera el paquete y se corre `check.py`. Recién ahí se toma P02.

**Cómo responder:** por lista (`aceptar la lista ACEPTAR EN BLOQUE`) o por id (`aceptar`, `aceptar con cambios: …`, `rechazar: <alternativa>`).

**Cómo se comprobó la evidencia:** cada fila se contrastó con el árbol `upstream/pekko` en v2.0.0 (y su diff contra v1.7.1) y con los casos grabados de Pekko 2.0.0; donde el oráculo ejecutable ya tenía el caso y Rust aún no lo reproduce se midió con `oracle/run.sh` (se indica «Medido en 2.0.0»). Para la mayoría de las áreas (HOCON, FSM, routers, serialización, Typed, testkit) no hay caso grabado: la evidencia es de lectura del código y de los specs 2.0.0, y se dice así. Un riesgo «alto» significa que deshacer la decisión cambia API pública o comportamiento observable.

**Vínculo con el PR de mantenimiento #220:** Q-PATH-6 (licencia de `uri.rs`/`jstring.rs`) bloquea reescribir sus encabezados; ver su fila.

**Total: 52 decisiones** — ACEPTAR EN BLOQUE: 16, REVISAR: 28, BLOCKING: 8.
